# Roblox Mouse Changer for macOS
<br>
To run "./player.sh" you have to enter this command:

```sh
chmod 755 ./player.sh
```
in the same directory as the file
<br>
## Running the command
To run the command use:

```sh
./player.sh
```
in the same directory as the file

## Using Custom Cursors
Go to ./Cursors to add/edit the cursors.
<br>
The images must be 64 x 64 to work.
